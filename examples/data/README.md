# Saved reference inputs

`inputs/` preserves the relative paths expected by the reference renderers:

- `data.json`: repository example arrays and uncertainty values.
- `figure-height-baseline.json`: dimensions before the approved height revision.
- `emphasis-examples/data.json`: saved illustrative focus/reference series.
- `urban-style-samples/`: extracted data, source credits and the original workbook.
- `originals/`: original reference artwork used for comparisons.
- `s3-design-study/cobalt-brick-gold/`: earlier comparison images required by the multi-panel gallery.
- `note-size-study/baseline-article-layout.json`: the fixed geometry used for the type-size study.

These are inputs and provenance, so they belong in Git even when a required input
is an image or workbook. Source credits and upstream licenses remain applicable.
